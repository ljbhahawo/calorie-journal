# 表单校验与搜索体验

用途：记录用户2026-10-24新增的表单交互要求，进入接续1.14.0，保留已发布1.13及旧版本。状态：正式源码、真实WPF、桌面及回滚验收通过，发布状态见开发进度。

- 每日表单保存时按页面顺序检查必填：日期、餐次、食物名称；重量模式要求可食重量、每100克能量及单位；直接模式要求本项能量。蛋白质、时间、状态、备注和查库均为选填。热量可为明确零，不能把空当零。标签明确“必填/选填”，条件字段注明所用模式。
- 缺少必填项时不写数据库，显示具体原因，自动滚动并聚焦第一个缺失字段；再次提交仍可定位。空日期或未确认的非法日期不能沿用旧绑定日期静默保存。保留草稿，模式与已填数值不改变；现有无效数字和范围校验保持。
- 表单查库采用搜索输入框及下拉候选，按中文、别名、英文过滤个人食物库。鼠标或键盘明确选择后引用，输入/浏览候选不自动保存或替换食物；Escape关闭、无匹配提示、清空后可重新搜索。原名、状态、每100克数值和来源可核对，不增加网络。
- 共享输入框清空按钮在单行和多行输入区域均上下居中，保留原绑定、撤销、只读/禁用/空输入保护。

验收：真实WPF逐个缺失字段保存、焦点/可见区域/错误提示/数据库无变化、重复提交、零值有效、切换模式及草稿保护；搜索鼠标与键盘选择/取消/无匹配、来源快照；多种高度清空按钮中心一致。完整回归、正式源码重建、独立程序桌面、版本8往返及大备份脚本恢复通过后提交推送发布。身体趋势按已确认X05同期独立检查，不改数据格式。

## 1.15.1：名称输入与食物库搜索合并

2026-11-13确认将每日表单的独立查库输入框合并到“食物名称”。表单和表格复用同一候选控件：按中文、别名或英文查询个人食物库，展示名称、原名、状态、每100克数值与来源；最多显示12个结果。方向键浏览，回车或鼠标明确选择后引用，Escape关闭。没有匹配时保留输入，继续手填；清空关闭候选。选择候选不立即保存；表格在没有选中候选时沿用回车保存规则。

手改已引用的名称时解除旧食物关联，保留已填数值供用户核对；加载已有记录仍保留历史快照。沿用现有个人食物库和搜索规则，不联网、不更改数据库/备份格式9或依赖。验收覆盖同框手填、无匹配、键盘和鼠标引用、来源及单位能量、清空和重新搜索、无误保存、表格回归以及与1.15.0同格式回退。

# 摄入目标与锻炼记录

用途：1.11.0 / I5的R23目标部分、R24及T32剩余、T33的实施设计。状态：2026-10-23正式本地验收通过，发布状态见[开发进度](progress.md)；1.10.0及全部旧稳定完整包保持独立。

## 范围与操作

新增“目标与锻炼”页，分为目标和锻炼两个子页，沿用中文表单、列表和固定操作区域。目标由用户输入每日大卡及生效日期，不根据身体记录推荐数值。新增调整保留旧条目；按日期取最近一条已生效目标，直到下一条生效日前一天。允许以“暂停目标”的空值终止比较，不能用0冒充未设置。

目标日期唯一。重复日期拒绝并提示选择已有记录。修改或删除已有条目属于明确历史修正，保存前提示原区间及修正可能影响的比较范围；取消保留草稿，不静默覆盖。目标历史显示生效起止日期、目标或暂停状态、备注。未来目标可以预先设置，不改变当前目标。目标范围为0.1–99999.9大卡，最多一位小数；备注最多2000字。

每日记录显示所选日期目标及摄入差值，独立页可选择对比日期。未设置/暂停目标或当天未记录时不计算差值；有记录且为0时按真实零比较。展示“距目标尚差/已超过/与目标相同”，不标为健康评价或完整记账。新目标不改写之前区间，摄入及周/月统计保持原值。

锻炼按日记录活动名称（最多100字）、时长分钟（0.1–1440，最多一位小数）、可选用户输入消耗（0–99999.9大卡，最多一位小数）、备注（2000字）。支持增删改、最近30天默认查询及最多366天区间，未来记录拒绝。相同活动可多次记录，以独立ID区分。空热量显示“未填写”，明确零显示0.0；汇总显示次数、时长、已填写热量之和及未填写次数，不把缺失消耗当成零。运动不抵扣摄入，也不增加目标额度，不提供净摄入、MET估算或联网服务。

关闭、取消、切换编辑对象保护未保存草稿；备份恢复有任一草稿时阻止。恢复范围预览包含目标及锻炼数量，旧格式缺失类型清楚提示为空。

## 数据与回滚

Core新增IntakeGoal、ExerciseRecord及目标生效区间/比较模型，JournalService校验规则；SQLite新增intake_goals（生效日期唯一）与exercise_records（日期索引），保存带索引校验的JSON及稳定ID。金额/分钟使用明确缩放的64位整数，不增加依赖。数据库及备份升为6，新快照必须含两个数组，旧格式1–5禁止夹带新数组。完整备份恢复在一个事务内包含九类集合及设置；旧格式恢复会清空新增类型，之前全部数据先完整归档。

升级前保留结构5的SQLite完整备份和1.10可读JSON。旧1.10必须拒绝结构6且不修改数据库；回退需显式选择升级前结构5恢复点，先归档结构6全部当前数据。旧视图只能显示恢复点时已有资料，不显示新版目标、锻炼及恢复点后新增记录。返回1.11通过安全恢复入口恢复结构6归档；不自动合并旧版期间新增记录。真实用户库不参与演练，保留1.10及全部旧完整包、源码、锁文件和校验清单。

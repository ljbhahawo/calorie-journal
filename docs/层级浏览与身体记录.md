# 层级浏览与身体记录

用途：规定用户2026-10-23新增需求的1.9.0实现范围、数据保护和验收。状态：2026-10-23正式本地验收通过；1.8.1和旧版完整保留，实际发布状态见[开发进度](progress.md)。设计在实现前建立。

## 范围与操作

R30：每日按餐使用“餐次→食物”两层结构，连续列表使用“日期→餐次→食物”三层结构。日期标题、餐次底色、左侧引导线和逐级缩进共同标明归属，不只依靠颜色；保留小计、空餐状态、滚轮浏览及增删改入口。连续列表仍按餐次ID区分自定义/停用餐次，历史名称继续显示；不改变摄入、草稿和滚动区间规则。

R31：增加“身体记录”页，按日期保存体重kg，可选身高cm、当时年龄、公式性别选项及腰围cm、备注。每天一条，重复日期明确要求修改已有记录，不静默覆盖。提供日期区间查询、记录增删改、真实测量首尾变化和最新记录摘要；未测量日期不填零、不插值。新建时可带入最近一次已保存的身高、年龄和公式选项，必须核对当时资料；编辑和历史快照不被以后资料更新改写。不收集生日、姓名或账户，全部资料只存本机。

R32：有体重/身高即可显示BMI数值，公式为kg÷m²；不增加成人/儿童或不同地区分类。代谢参考采用Mifflin–St Jeor 1990简化静息能量方程：10×kg+6.25×cm−5×周岁，男公式加5、女公式减161。年龄和公式选项可不提供；资料不完整或年龄不在原研究19–78岁范围时明确未估算，仍可保存体重。非正代谢结果不显示为有效估算。说明其为静息估算、非实测、非每日摄入目标，不自动抵扣或改变摄入与目标。

体重精确0.01kg，身高/腰围精确0.1cm，年龄为1–120整数；技术录入范围体重1–1000kg、身高50–300cm、腰围1–300cm，范围只用于拦截输入错误。计算保留decimal精度，BMI显示2位，代谢显示1位，统一四舍五入。每条保存当时输入与公式版本，未来计算方式变化须显式处理版本，历史不套用新资料。

## 模块与数据

沿用Core规则/计算、Infrastructure真实SQLite、Desktop MVVM；不增加依赖。新增BodyMeasurement模型、BodyCalculator和业务接口，SQLite增加body_measurements表（主键、唯一日期、版本化JSON内容）。数据库5/备份5新增BodyMeasurements数组；格式1–4明确不含新类型，恢复时身体列表为空，恢复前完整归档当前数据。旧结构1–4升级前生成旧程序可读的数据库和JSON恢复点，事务失败不改变原结构/设置/内容。

返回1.8.1须选结构4恢复点，回退前完整归档七类集合和设置。旧版不能展示新增身体资料，后来摄入及身体资料保留在新版归档；返回1.9.0恢复该归档并逐项比较。演练仅用独立测试目录，不覆盖原稳定包、源码、标签或Release。

## 验收顺序

1. Core和真实SQLite：BMI和两种公式的明确算例、缺失/年龄范围、精度、非法输入、重复日期、修改移动冲突、删除、重启、完整备份、旧格式恢复、真实SQL故障整体保护；摄入合计不变。
2. 真实WPF：三层/两层缩进的实际边界位置、ID分组与小计、滚动、增删改；身体表单/预览/保存/编辑/删除/日期筛选和弃稿确认。最小920×600、100%/125%/150%/200%布局缩放按钮可达，空状态与缺失值明确。
3. 独立源码锁定重建、全部核心回归及真实桌面操作，自包含包启动/恢复/拒绝错误备份，实际4→5升级与5→4→5安全回滚保留身体记录、快照及录入设置。
4. 完成后保留1.8.1及旧版，审查隐私，按用户长期授权提交推送、稳定附注标签和公开程序/上一版回滚包/校验清单。生命周期和未验证项记录在开发进度，不以构建成功代替验收。

## 公式来源（2026-10-23核对）

- [CDC：Calculating BMI](https://www.cdc.gov/growth-chart-training/hcp/using-bmi/calculating-bmi.html)，读取可访问页面正文；公式kg÷m²。
- [CDC：About BMI](https://www.cdc.gov/bmi/about/)，读取可访问页面正文；BMI不直接区分脂肪、肌肉和骨量，本版只显示数值。
- [Mifflin等，1990，PMID 2305711](https://pubmed.ncbi.nlm.nih.gov/2305711/)，读取完整PubMed页面及摘要，未宣称读到论文全文；摘要明确简化公式、单位和19–78岁研究范围。DOI：10.1093/ajcn/51.2.241。公式版本mifflin-1990-simple.v1。

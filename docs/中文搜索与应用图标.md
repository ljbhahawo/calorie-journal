# 中文搜索与应用图标

用途：维护1.6.0的R18/R19实施设计、公开词表来源、构建资源和T27/T28验收。状态：2026-10-23候选功能验收通过，正式交付结果见[开发进度](progress.md)。整体阶段见[后续功能开发计划](后续功能开发计划.md)。

## 数据和中文描述

官方营养目录`data/lookup/usda.json`保持原样；新建`data/search/usda-terms.json`，维护英语食材、状态与中文描述的对应关系，`data/search/aliases.json`维护常用词组。中文是本项目整理的检索辅助，不声称是USDA官方译名，也不声称每条英文长描述已经逐字翻译。

`scripts/prepare_chinese_index.py`从真实7793条目录和词表生成`data/lookup/usda-zh.json`及忽略目录下的逐项覆盖审计。索引以来源ID关联，不包含新的营养值；声明营养目录版本及SHA256、词表和别名SHA256、中文索引版本及整理方法。没有中文描述或长度无效时停止生成，保留审计。只有宽泛类别的条目额外保留具体原文限定，不靠填入类别名称冒充完整翻译；少数没有可靠中文通名的地方食名保留原名并明确标注。

中文名称由具体食材、部位及状态词组成。牛肉、鸡肉等各部位独立；豆类中的kidney不译为肾脏，蘑菇中的oyster不译为牡蛎，糙米、奶粉、鸡胸肉、食用油等按实际上下文组合。该规则不改变原文中的物种、品牌或数值，用户查看英文原始名称后选择实际相符条目。品牌和地方食名不推测成相似的常见食物。

原60项已整理中文映射继续使用；整目录额外提供中文词组检索。英文原名、来源ID、目录版本、每100克大卡、原始链接继续保留；中文索引版本写入来源说明，使用户保存食物后仍可核对整理依据。用户自己维护的名称、别名和既有摄入快照不由索引覆盖。

## 模块和搜索

Core的`FoodSearch`负责Windows简繁转换、Unicode全半角归一、常用别名和食材词的最长匹配、组合关键词及排序。食物库和参考目录使用相同规则；查询可不加空格，如“去皮鸡脯生”。食材/状态使用内部词边界，防止“不加糖”命中“加糖”、“花生”被拆成生制、“蛋白质”被认成蛋清。一般食材和具体部位可有明确的上级检索关系，保留具体名称和原始来源，不合并营养值。

参考目录按对象缓存已生成的只读检索文档，更新资料时新对象建立新索引，旧对象可被回收；不将私人查询词保存为持久缓存。搜索先按完整名称及同义名称、名称开头、别名和相关描述排序；继续每个来源最多显示100项，并显示总匹配数，引导增加关键词缩小范围。

地区多义词单独维护食物上下文规则。例如TFDA的花生俗名包含“土豆”，其原文和字面查询保留，但不能因此让“马铃薯/洋芋”命中花生；规则只影响检索文档，不修改原来源别名或数据。大西洋鲑、大西洋鳕等具体物种描述也不作为全部鲑鱼/鳕鱼的等价别名，品种以来源原文核对。

Infrastructure的`ChineseFoodIndex.Apply`校验中文索引、营养文件及程序内嵌词表的版本和哈希、来源ID唯一性及字段长度，再以只读方式附加中文描述。校验不通过明确终止该目录加载，不能静默使用不匹配的映射。界面沿用“使用随包资料”的显式读取入口。

查询窗口增加原始名称列，来源详情仍保留完整原文、状态及链接。中文字段带入新增食物后，用户核对保存才加入个人库。

## 数据兼容和回滚

数据库1、完整备份格式1、起始食物包版本保持不变；本版不迁移用户数据库。中文索引格式1单独管理，随完整应用版本保留。`ChineseIndexVersion`是内存元数据，不序列化到TFDA缓存，保证1.6主动更新产生的缓存仍可由1.5读取；验收须用旧版实际读回新缓存，不能仅推断兼容。

保留1.5.0完整程序和源码；回滚演练包含中文别名搜索后保存的USDA食物、TFDA食物及其摄入快照，检查返回1.5再到1.6均保留英文原名、数值、来源及备注。中文索引和图标随各版独立程序目录切换，不能修改旧包来实现回退。

## 图标资源

采用内置`image_gen`生成，使用透明背景的绿色餐盘/叶片图案。原图保存于`src/CalorieJournal.Desktop/Assets/app-icon.png`，`app-icon.ico`由`prepare_icon.py`使用Pillow标准编码器导出16/24/32/48/64/128/256像素图像；原图和透明通道保留，Pillow只用于资源导出，不成为应用运行依赖。桌面项目通过`ApplicationIcon`嵌入EXE，统一Window样式通过应用资源加载ICO。

Transparent pixels outside the rounded square, generous consistent margin. No text, numbers, letters, badges, shadows, mockup, border around canvas, utensils or extra objects, no watermark. Square image, one icon only, no surrounding scene. This is a production asset; provide genuinely transparent background.

## 验收与已知边界

- T27逐项检查7793条来源ID、英文原名及能量值不变，审计具体中文食材/状态与原文限定；140条中文案例按独立英文条件查找真实来源，保存匹配编号和真实耗时。测试不是以中文映射本身生成期望答案。
- 检查个人库的中文/简繁/别名、多词与无空格组合、无结果、排序、只读和用户自定义字段保护；检查索引缺失、重复、版本及哈希不符明确拒绝。
- T28核对七档ICO和透明通道、EXE提取图标与ICO像素一致、真实WPF窗口WM_GETICON大图标与ICO像素一致；实际观察标题栏图标和完整解压程序启动。当前工具未提供可定位的任务栏窗口，未单独进行任务栏视觉检查，不能把窗口系统图标检查表述为该项已观察。真实WPF另核对应用资源、英文列访问、中文USDA查询及保存来源。
- 执行所有核心回归、正式源码锁定重建、自包含包、完整备份及1.6→1.5→1.6往返，之后才标记稳定。当前开发中的通过项和失败记录不能替代最终交付验收。
- 中文词组帮助定位食物，不等同完整翻译；个别外国品牌及地方食名保留原文。无法仅从原文确定的物种和加工细节不推断。新同义词或新目录仍需补充审查及查询案例。

# 每日热量记录

Windows 11 本机离线摄入记录软件。首版功能、桌面操作及必要回归已完成，包含运行时的1.0稳定版正在归档验证。当前产物见 [本地版本目录](artifacts/releases)，准确版本及验证状态统一维护在 [开发进度](docs/progress.md)。

## 已确认的产品目标

- 分项记录每天摄入的大卡，支持早餐、午餐、晚餐及任意加餐。
- 手动输入热量，或选择食物库条目后按重量和单位热量计算。
- 内置食物热量库，允许用户搜索、新增、修改和删除食物。
- 本机离线、单人使用，无需注册；支持后续维护和软件更新。

## 使用方式

打开应用 → 选择日期和餐次 → 搜索食物并输入重量，或手动输入本项大卡 → 保存 → 查看餐次小计和当天合计。历史记录可以修改和删除；食物库单独维护。

从本地版本目录选择候选压缩包，完整解压后双击`app/CalorieJournal.exe`。包内包含.NET运行时、源码快照、校验清单及回滚入口，日常使用不需要安装开发环境。程序与用户数据分开保存，详细操作见 [使用说明](docs/使用说明.md)。

## 当前限制与后续安排

项目内已准备.NET SDK 10.0.402及锁定依赖。已整理60项有来源的基础食物，支持中文搜索和用户增删改；15项真实SQLite测试、WPF绑定与焦点、48项布局缩放访问、四页桌面操作、系统备份恢复对话框及候选包实际启动通过。当前150%系统DPI已实际操作；其他DPI的跨显示器切换及另一台干净Windows机器尚未验证。

用户已授权：首版全部验收通过且仍有可用额度时，自主进行小版本改进，可按实际需要加入简洁的锻炼记录、减脂管理、菜谱等功能。每次保留上一稳定版及数据恢复路径，实际验证后交付新版；候选功能、实施状态及回滚演练结果分别记录，见 [版本迭代与回滚](docs/版本迭代与回滚.md)。

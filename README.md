# 每日热量记录

Windows 11 本机摄入记录软件，日常记账离线使用。当前稳定版1.5.0新增热量资料查询：USDA 7793项与TFDA 2213项参考目录、中文/简繁/英文搜索、多个来源及原始链接、选中后带入新增食物。TFDA资料可由用户主动联网更新。原有分餐摄入、60项起始食物库及维护、重量计算、连续列表、历史、备份恢复、历史复制、文字及复制表格导入继续保留。正式源码重建、实际联网、桌面流程、完整程序及返回1.4.0已通过。

## 已确认的产品目标

- 分项记录每天摄入的大卡，支持早餐、午餐、晚餐及任意加餐。
- 手动输入热量，或选择食物库条目后按重量和单位热量计算。
- 内置食物热量库，允许用户搜索、新增、修改和删除食物。
- 本机离线、单人使用，无需注册；支持后续维护和软件更新。

## 使用方式

打开应用 → 选择日期和餐次 → 搜索食物并输入重量，或手动输入本项大卡 → 保存 → 查看餐次小计和当天合计。历史记录可以修改和删除；食物库单独维护。

从GitHub Release或本地版本目录选择稳定压缩包，完整解压后双击`app/CalorieJournal.exe`。包内包含.NET运行时、源码快照、校验清单及回滚入口，日常使用不需要安装开发环境。程序与用户数据分开保存，详细操作见 [使用说明](docs/使用说明.md)。

开发者可克隆仓库，使用PowerShell运行`.\scripts\Initialize-Environment.ps1`及`.\scripts\Test-Project.ps1`准备项目内环境并验证。Git只保存源码和公开数据；历史日志与本地程序归档不进入源码仓库，版本来源和管理方式见[Git管理说明](docs/Git管理说明.md)。

## 当前限制与后续安排

项目内已准备.NET SDK 10.0.402及锁定依赖。正式1.5.0的31项业务/SQLite、真实WPF与156项布局访问、实际TFDA下载、取消和缓存失败保护通过；源码独立重建与返回1.4.0再升级保留双来源食物、3条完整测试摄入及餐次。参考目录不会自动加入个人食物库；USDA原60项有中文映射，其余支持英文搜索。连续列表单次最多366天，可调整区间查看更早记录。直接读取Excel文件、图片和PDF尚未实现。当前150%系统DPI已验证；跨显示器DPI切换、空包缓存及另一台干净Windows机器尚未验证。

用户已授权：首版全部验收通过且仍有可用额度时，自主进行小版本改进，可按实际需要加入简洁的锻炼记录、减脂管理、菜谱等功能。每次保留上一稳定版及数据恢复路径，实际验证后交付新版；候选功能、实施状态及回滚演练结果分别记录，见 [版本迭代与回滚](docs/版本迭代与回滚.md)。
